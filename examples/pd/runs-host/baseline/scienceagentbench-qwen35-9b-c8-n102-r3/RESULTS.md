# ScienceAgentBench verified102 · Qwen3.5-9B colocated

## 结论与计时口径

102/102题均运行至终态，整批墙钟时间 **2523.619秒（42分03.6秒）**。
这是有上限的执行测试，不是102题全部答对：68题退出码为0且生成本轮目标文件，
21题重复错误程序后停止，6题达到纠错上限，4题工具执行超时，3题被SIGKILL终止。
没有运行官方科学正确性/图像评判 grader，不能将68/102作为正确率。

从提交102题到最后一题终态计时，含排队、容器启动、模型调用、工具执行、纠错和清理；
不含数据下载、科学镜像构建、模型加载。每题墙钟从获得并发槽开始，
不含此前在102题任务队列中的等待。平均单题时间不能直接乘102得到8并发整批时间。

最多10次执行，但最后一次错误后可能仍生成一份未执行的修正程序，故模型调用最多11次。

## 非成功终态

- 重复错误程序停止：1,12,16,28,30,33,39,48,51,52,60,61,62,64,65,69,74,86,95,99,102。
- 纠错上限：19,25,49,97,98,101。
- 工具超时：9,40,47,76；每次工具900秒上限，不是整题900秒。
- SIGKILL：72,77,83。未保留足以证明OOM的cgroup记录，因此不将SIGKILL一概标成OOM。

错误包含模型生成的错误API、数据格式/列名处理、科学依赖/离线限制等。
例如题11最初缺cv2，但随后改用其他实现并生成文件；不能把所有出现过缺包的题都算环境失败。
本轮未在运行中改变依赖镜像或手动修正模型答案。未来若计算科学正确率，
应对保存的68个文件执行官方grader，并另行控制环境兼容性。
